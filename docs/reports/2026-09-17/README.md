# Ember working paper

[Read the draft](ember_status_and_future.pdf).

The paper compares the 0.1-solar-mass Ember track with LBA97 and MESA,
including atmosphere and diffusion comparisons, helium-3 pulse tests,
and a conditional lifetime timeline. Pulse calculations remain provisional;
their peak and outcome are not established.

The supplied LaTeX and figure PDFs reproduce the document layout. Build with
`tectonic ember_status_and_future.tex` (tested with cached packages). Numerical input files and executable
changes for all development calculations are not included in this paper update.
